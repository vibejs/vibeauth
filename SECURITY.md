# Security

Do not disclose exploitable authentication vulnerabilities in a public issue. Contact the
maintainers privately; use GitHub private security advisories when that channel is enabled.
Never attach cookies, session tokens, reset links, private keys or production database dumps.

See docs/security.md and docs/threat-model.md for integration boundaries. This project has
not received an independent security audit. Review the exact Better Auth version and its
security advisories when upgrading. The npm artifact is not published by this repository's
local verification workflow.
