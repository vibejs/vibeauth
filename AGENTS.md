# VibeAuth

Use only public Vibe.js and Better Auth APIs. English only. Relative TypeScript imports end in `.ts`.
Better Auth owns authentication mechanisms. Never disable origin or CSRF checks.
Keep browser, server and router exports isolated. Never store credentials in localStorage.
Run `pnpm check`, integration tests, example builds, docs build and `pnpm pack-check`.
Never publish, push, deploy or create remote resources without explicit authorization.
Never add Co-Authored-By, Signed-off-by, Generated-by or AI attribution trailers to commits.
